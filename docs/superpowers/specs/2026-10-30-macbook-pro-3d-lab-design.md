# MacBook Pro 3D 实验室设计基线

日期：2026-10-30。本文记录当前已存在实现及本轮交付边界；用户已明确要求直接创建、运行和测试，因此采用本会话内联执行，不再追加需求确认轮次。

## 目标与边界

参考机为 MacBook Pro 14-inch（2021，A2442）的标准 M1 Pro 配置：8 核 CPU（6P+2E）、14 核 GPU、16GB 统一内存、512GB SSD。目标是在一个页面内连接三种观察尺度：维修工程师的部件拆解、操作系统的数据路径、体系结构的指令与芯片功能块。

非目标：不运行完整 macOS；不模拟 Darwin/XNU；不声称拥有 Apple CAD、PCB Gerber、裸片版图或未公开微架构；不把三维近似用于维修尺寸测量；不把模拟温度、功耗、I/O 时延当成实机 benchmark。

## 已确定的技术与架构

- React 18 + TypeScript + Three.js，经 @react-three/fiber 和 drei 渲染；Zustand 管理界面与场景状态。
- `src/data/`：固定规格、部件、来源与 provenance。
- `src/three/`：真实几何模型、拆解插值、相机、剖切、数据包和芯片教学抽象。
- `src/sim/cpu/`：AArch64 汇编、编码/解码、顺序教学核心、缓存、MMU/TLB；执行状态通过 `src/sim/lab.ts` 与 UI/三维共享。
- `src/sim/memory/`、`storage/`、`gpu/`、`sched/`：可执行模型，不由预录动画替代。
- `src/sim/flows/`：六个场景由模型生成步骤、检查表、屏幕内容和有元数据的数据包。
- `src/ui/`：左侧模式/场景，中央三维，右侧状态/实验，底部时间线。

## 真实性与来源层级

1. **官方规格**：Apple 技术规格、平台安全、开发者文档。
2. **拆机实测**：iFixit 对应机型照片和指南直接支持的事实；芯片丝印只代表资料样机，不外推为所有机器的唯一供应链配置。
3. **资料推导**：第三方测量、容量推算、近似布局。
4. **教学抽象**：芯片功能块、五级流水线、缩小缓存和页框、NAND 时序、热模型等。

硬性约束：统一内存为 SoC 封装组件内的两颗 LPDDR5，不是 DIMM；NAND 焊接在逻辑板，不是 M.2/SATA/机械盘；HDMI 和 SDXC 是板载件，不能描述为独立可拔接口卡；未公开裸片布局必须显示“教学抽象”。

## 交互与状态一致性

- 模式 A：0–100% 爆炸滑块与 0–10 拆解决策共用同一状态；三维帧循环只负责平滑插值。
- 模式 B：每个场景步骤包含 `inspect`、`packets`、`durationUs`、`highlights`，点击数据包可查看端点、大小、操作与原因。
- 模式 C：机器码由 Clang 金标准校验；指令、PC、寄存器、缓存、内存、MMU 同步更新；芯片功能块不是官方裸片图。
- 实验：真实固定参数只读，实验参数可调；内存/调度快照可回放，CPU 通过撤销/确定性重放回放。
- 日志、数值与图形必须来自同一模型状态，不另造随机装饰结果。

## 视觉设计

- 色彩：石墨背景 `#0c0e13`、分层面板 `#12151c/#171b24`、主文本 `#e6e9ef`、结构蓝 `#3b82f6`、数据青 `#22d3ee`；橙红仅用于热/警告。
- 字体：系统 SF Pro/PingFang 负责说明，SF Mono/Menlo 负责地址、机器码和数值；不为装饰另引字体。
- 布局：中央三维是唯一视觉主角，左右栏保持克制、密集但可读；底部控件随模式切换，避免无关按钮占位。
- 动效：只响应拆解、聚焦、数据流和用户操作；无循环装饰性 UI 动效。
- 桌面实验室优先；窄屏不是本轮验收目标，不声称移动端已适配。

## 验收

- `npm test`：ISA 金标准、执行语义和系统模型全部通过。
- `./scripts/gen-golden.sh` 前后 `tests/clang-golden.json` SHA-256 不变。
- `npm run build`：TypeScript 和 Vite 生产构建成功。
- `scripts/browser-smoke.mjs`：真实 Chrome/WebGL、核心交互、截图、运行时错误检查通过。
- 当前模型不能读取截图，视觉部分只验证 DOM 几何、像素非空和文件产物；不把这项限制隐藏成“已人工看图”。
